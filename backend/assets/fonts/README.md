The embedded OncoBrief Sans font combines the Latin, Latin Extended and Devanagari subsets of IBM Plex Sans Devanagari Regular from the repository's installed `@fontsource/ibm-plex-sans-devanagari` package. The modified font is renamed OncoBrief Sans and distributed under the included SIL Open Font License.

It supplies the glyphs used by English, Hindi and Marathi exports. ReportLab uses HarfBuzz shaping through `uharfbuzz`. The browser uses the original Fontsource font packages separately.
